> 🌐 **نسخة جاهزة على الإنترنت:** `https://osint-console-ar.vercel.app` — نفس المنصة تعمل على Vercel (دوال serverless) ويمكن تشغيلها محلياً بأمر واحد.

منصة ويب واحدة عربية (RTL) تجمع **36 وحدة تحقيق** تعمل فعلياً من المتصفح، مبنية على مصادر مجانية
لا تطلب تسجيلاً ولا اشتراكاً ولا مفتاح API. كل البيانات تُعالج داخل خادمك، ولا تُرسل إلى أي طرف ثالث
عدا الاستعلام نفسه الذي تطلبه.

```
git clone https://github.com/elias0878/osint-console && cd osint-console
python3 server.py          # ثم افتح http://localhost:8000
```

**الشاشة الافتراضية = «المسح الشامل»**: تكتب الهدف مرة واحدة، فيكتشف نوعه (نطاق/IP/بريد/اسم مستخدم/هاتف/
عملة/CVE/هاش/MAC/إحداثيات) ويشغّل **كل الوحدات المناسبة بالتوازي**، يعيد المحاولة تلقائياً عند أي فشل،
ولا يتوقف حتى ينتهي — مع شريط تقدّم، حالة كل وحدة على حدة، وملخص نهائي + تصدير JSON/تقرير HTML كامل.

بلا pip install، بلا Docker، بلا إنترنت إلا للاستعلامات نفسها. يعمل على Python 3.9+ (اختُبر على 3.13).

## 3) كيف يعمل «المسح الشامل» (بلا توقف)

| الخاصية | التفاصيل |
|---|---|
| **تغطية كاملة وشفافة** | كل هدف يمرّ على **29 وحدة**: ما ينطبق يُنفّذ، وما لا ينطبق يُعرض صراحةً بسببه («يتطلب رفع ملف»، «غير منطبق — الهدف ليس عنوان عملة» …) — لا شيء يُخفى أو يُتجاهل. |
| **اكتشاف النوع تلقائياً** | 11 نوعاً: نطاق، IP، بريد، اسم مستخدم، هاتف، عملة، CVE، هاش، MAC، إحداثيات، وروابط URL (تُطبَّع تلقائياً). |
| **لا يتوقف** | كل وحدة لها مهلة مستقلة (80 ثانية)، وفشل وحدة لا يؤثر على غيرها، ثم **جولة إصلاح آلية** تعيد كل ما فشل مرة أخرى قبل إعلان النتيجة. |
| **تقدّم مضمون** | المهمة تعمل في الخلفية على الخادم، والواجهة تستعلم عنها كل 0.6 ثانية (`/api/sweep/start` + `/api/sweep/poll`) — تعمل خلف أي وسيط أو استضافة، عكس البث المباشر الذي قد يُحجَب. |
| **إعادة محاولة فردية** | أي وحدة فاشلة يظهر بجانبها زر «إعادة محاولة هذه الوحدة» فوراً. |
| **عرض كل المعلومات** | جدول لكل قائمة، ومفتاح/قيمة لكل حقل، وأقسام قابلة للفتح، وJSON خام لكل وحدة — ثم تصدير الملف كاملاً. |

الواجهات: `GET /api/sweep?q=…` (متزامن) · `GET /api/sweep/start?q=…` → `{"job":"…"}` · `GET /api/sweep/poll?id=…&from=N` (تحديثات تراكمية) · `GET /api/sweep/stream` (SSE اختياري).

## 4) النشر على Vercel (النسخة الحيّة)

الموقع الحيّ: **https://osint-console-ar.vercel.app** — نشر إنتاجي واحد يعمل عليه:

```
الملفات:
  index.html          ← الواجهة (ملف ثابت واحد، بلا build ولا npm)
  api/index.py        ← دالة serverless واحدة (WSGI) تُخدِّم كل /api/*
  routes.py           ← مُوزّع مشترك: dispatch(path,args) + plan(q)
  catalog_meta.py     ← تعريف الوحدات والمجموعات (36 وحدة)
  vercel.json         ← rewrites + headers + maxDuration
```

- إعادة النشر: `vercel deploy --prod` (أو اربط المستودع بـ Vercel ليتحول كل push إلى نشر تلقائي).
- `server.py` (خادم التطوير المحلي) مُستثنى في `.vercelignore` حتى لا يُحسب كـ entrypoint بديل.
- **لا حالة على الخادم**: Vercel serverless لا يحتفظ بذاكرة بين الطلبات، لذلك منسّق «المسح الشامل» يعمل في المتصفح: يطلب `/api/plan` ثم ينادي `/api/<module>` بالتوازي (5 معاً) مع 3 محاولات لكل وحدة — نفس السلوك تماماً محلياً وعلى الإنترنت.
- Supabase **غير مطلوب**: التطبيق بلا قاعدة بيانات ولا مفاتيح؛ يمكن إضافته لاحقاً لحفظ سجل المسحات اختيارياً.

## 5) التشغيل المحلي

```bash
cd osint-console
python3 server.py                 # http://localhost:8000
python3 server.py --port 9000     # منفذ آخر
./run.sh                          # نفس الشيء + فتح المتصفح
docker build -t osint-console . && docker run -p 8000:8000 osint-console
```

> الخادم يربط `0.0.0.0` ليعمل خلف أي وسيط/استضافة. لا يستخدم أي ملف تعريف أو قاعدة بيانات:
> كل الحالة في الذاكرة (كاش 5-60 دقيقة) وتُصفَّر عند إعادة التشغيل.

## 7) واجهة API

كل نقطة ترجع `{"ok":true,"data":{...},"ms":123}` أو `{"ok":false,"error":"رسالة عربية"}`.

| GET | الوظيفة |
|---|---|
| `/api/dns?q=example.com` | سجلات DNS + PTR |
| `/api/rdap?q=…` | RDAP (نطاق/IP/ASN) |
| `/api/whois?q=…` | WHOIS خام |
| `/api/subdomains?q=…` | نطاقات فرعية |
| `/api/certs?q=…` | مُصدرو الشهادات |
| `/api/ip?q=8.8.8.8` | تحليل IP |
| `/api/tls?q=host` | شهادة TLS |
| `/api/http?q=url` | فحص HTTP + سلسلة التحويل |
| `/api/robots?q=url` · `/api/wayback?q=…` | robots / أرشيف |
| `/api/ports?q=host[&ports=22,80]` | فحص منافذ |
| `/api/urlscan?q=domain:x` · `/api/flight?q=lat,lon&dist=40` | urlscan / ADS-B |
| `/api/username?q=` · `/api/email?q=` · `/api/phone?q=` | هوية |
| `/api/github?q=` · `/api/dorks?q=&kind=` · `/api/hash?q=` | هوية |
| `/api/cve?q=` · `/api/crypto?q=` · `/api/company?q=` | استخبارات |
| `/api/geo?q=` · `/api/revgeo?q=lat,lon` · `/api/distance?q=…` · `/api/weather?q=` · `/api/earthquakes?q=2.5/day` | جغرافيا |
| `/api/threat?q=` · `/api/reverseip?q=` · `/api/oui?q=` · `/api/wikipedia?q=` · `/api/news?q=` | مصادر إضافية |
| `/api/catalog?q=&cat=` | دليل الأدوات |
| `/api/investigate?q=&kind=auto` | تحقيق شامل |
| `/api/selfcheck` · `/api/health` · `/api/stats` | صحة النظام |

| POST | الوظيفة |
|---|---|
| `/api/password` `{"q":"…"}` | قوة + كشف تسريب (لا تُخزَّن) |
| `/api/ioc?enrich=1` `{"q":"نص"}` | استخراج + إثراء المؤشرات |
| `/api/file` (multipart) | تحليل ملف |

## 8) الأدوات مفتوحة المصدر — نتيجة التحميل الفعلي

من 1738 عنصراً في القائمة الأصلية، **148 رابطاً** يشير إلى مستودعات كود (الباقي مواقع ويب لا تُحمَّل).
شُغِّل سكربت التثبيت فعلياً على كل المستودعات، والنتيجة الموثّقة في `docs/oss_install_report.csv`:

| النتيجة | العدد | التفصيل |
|---|---|---|
| نُسخت بنجاح | **136** | كود كامل جاهز في `tools/<repo>/` |
| موجودة مسبقاً | 2 | من اختبار السكربت |
| **روابط ميتة (404)** | **8** | المستودع حُذف أو أُغلق — عيب في القائمة الأصلية |
| انتقل (301) | 1 | `osintambition/…` → `OSINTVerseHQ/Social-Media-OSINT-Tools-Collection` |
| رابط غير صالح | 1 | رابط `blob` لملف وليس مستودعاً |

أي أن **138 مستودعاً صالحاً** من أصل 148 (93%). الكود (8.4 GB) لا يُحفظ في هذه المساحة
لأن حدّ الحفظ ~128MB، لذلك يُعاد تحميله بأمر واحد على جهازك:

```bash
./scripts/install_oss_tools.sh --deps --jobs 6     # 148 مستودعاً + متطلباتها
```

اختُبر التثبيت الكامل لاعتماديات أداة حقيقية: `sherlock` (pyproject → venv → `import sherlock_project` ✓).
السكربت يدعم `requirements.txt` و`pyproject.toml` و`setup.py` و`package.json`، ويكتب تقريراً لكل أداة:
`cloned / deps-ok / no-requirements / deps-failed / clone-failed`.

> الحقيقة الصريحة: كثير من هذه الأدوات يحتاج مفاتيح API أو خدمات مدفوعة لأداء وظيفته الكاملة
> (Shodan, VirusTotal, HIBP API, Dehashed…). المنصة هنا تغطي كل ما يعمل **بلا مفاتيح فقط**،
> والبقية متاحة كدليل بروابطها داخل «دليل الأدوات».

## 9) حدود معروفة (مهمة)

| القيد | التفصيل |
|---|---|
| **فحص المنافذ** | بيئات cloud/sandbox تمرّر TCP عبر وسيط يفتح كل الاتصالات، فتظهر كل المنافذ «مفتوحة». المنصة تكتشف ذلك تلقائياً وتوقف الفحص مع تحذير بدل إعطاء نتائج كاذبة. يعمل بشكل صحيح على جهازك/خادمك. |
| **حدود المصادر المجانية** | crt.sh وHackertarget وGDELT تحدّ الطلبات. المنصة تعيد المحاولة، تخزّن النتائج مؤقتاً، وتعيد نتيجة جزئية مع ملاحظة واضحة بدل الفشل. |
| **GDELT** | يسمح بطلب كل 5 ثوانٍ؛ عند التجاوز تظهر ملاحظة بدل الأخبار. |
| **تعداد أسماء المستخدمين** | إشارة «موجود/غير موجود» تختلف بين المواقع؛ الحالات غير الحاسمة تُعلَّم «غير محدد» مع رابط تحقق يدوي. |
| **المواقع المحجوبة آلياً** | كل ما يظهر في تدقيقنا كـ 403 (Cloudflare) يحتاج متصفحاً؛ دليل الأدوات يوفّر الروابط. |
| **الخصوصية** | الاستعلامات تمر إلى مزوّدي البيانات المجانيين (مثل ip-api, crt.sh). لتشغيل حساس استخدم شبكة تحت سيطرتك. |

## 10) الاستخدام المسؤول

هذه الأدوات للبحث المشروع: التحقق من صحافيين، تدقيق أمني، فحص أصولك، استجابة للحوادث،
أبحاث أكاديمية. **لا تستخدم** فحص المنافذ أو أي وحدة نشطة على أهداف لا تملكها أو لا تملك
تصريحاً كتابياً بفحصها. احترم شروط استخدام كل مزوّد وقوانين حماية البيانات (GDPR وغيرها).
